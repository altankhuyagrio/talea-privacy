Talea 개인정보 처리방침

시행일: 2026년 11월 13일

Talea는 [DEVELOPER NAME](“저희”)가 만든 iPhone 및 iPad용 개인 재무 관리 앱이에요. 간단히 말해, 사용자의 금융 기록은 사용자의 기기에 머물러요. Talea에는 사용자 계정도, 저희 서버도 없으며, 분석, 광고, 추적도 포함되어 있지 않아요. 저희는 사용자의 데이터를 볼 수 없어요.

Talea가 저장하는 데이터와 저장 위치

  • 사용자의 기록. 계좌, 거래, 예산, 목표, 사람, 태그, 그리고 첨부한 영수증과 초안은 기기 안에 있는 Talea의 비공개 저장 공간에 하나의 파일로 저장되며, 그 옆에 이전 저장본의 복구본이 함께 보관돼요. 둘 다 iOS 데이터 보호로 보호돼요. 즉, 암호화되어 있으며 기기가 잠겨 있는 동안에는 열 수 없어요.
  • 사용자의 환경설정(통화, 화면 스타일, 알림 시간, 앱 잠금 등)과 최신 환율표는 기기 안의 Talea 설정에 보관돼요.
  • 가져오기 대기 중인 항목. 다른 앱에서 영수증, PDF 또는 텍스트를 Talea로 공유하거나, 단축어의 Apple Pay 자동화(선택 사항)가 결제(가맹점, 금액, 카드 이름)를 알려 주면, 해당 항목은 기기 안에서 Talea와 Talea의 공유 확장 프로그램만 사용할 수 있는 폴더에서 대기해요. 항목이 초안이 되면 Talea는 해당 항목을 삭제해요.
  • 기기 백업. 다른 앱 데이터와 마찬가지로, 백업을 켜 두었다면 Talea의 파일은 iPhone 또는 iPad 백업(iCloud 백업 또는 컴퓨터 백업)에 포함돼요. 이 백업은 저희가 아니라 Apple 또는 사용자의 컴퓨터가 처리해요.

저희는 이 중 어떤 것의 사본도 받거나 보관하지 않아요.

iCloud 전송(선택 사항)

설정 → iCloud 전송을 사용하면, Talea는 작업 공간(기록, 영수증, 초안)의 전체 사본을 사용자 본인의 iCloud 계정의 비공개 데이터베이스에 업로드해, 다른 iPhone이나 iPad에서 다운로드할 수 있게 해요. 버튼을 탭하기 전에는 아무것도 업로드되거나 다운로드되지 않으며, 백그라운드에서 동기화되는 것도 없어요.

Apple은 이 데이터를 사용자의 Apple 계정에 속한 비공개 iCloud 데이터베이스에 저장하며, 이 데이터에는 Apple의 iCloud 이용 약관과 개인정보 처리방침이 적용돼요. 개발자인 저희는 이 데이터를 보거나 이 데이터에 접근할 수 없어요.

환율

Talea가 스스로 연결하는 서버는 open.er-api.com 하나뿐이에요. 이 서버는 ExchangeRate-API가 운영하며, Talea는 여기에서 그날의 공개 환율표를 내려받아요. Talea는 모든 통화가 담긴 표 전체를 내려받기 때문에, 이 요청으로는 사용자가 어떤 통화를 쓰는지 드러나지 않아요. 요청에는 개인 데이터나 금융 데이터, 식별자, 쿠키, 캐시된 데이터가 전혀 포함되지 않아요.

다른 인터넷 요청과 마찬가지로, 이 요청은 사용자 기기의 IP 주소에서 환율 제공업체의 서버로 전달돼요. 저희는 그 주소를 절대 받지 않아요. ExchangeRate-API의 서비스에는 ExchangeRate-API 자체의 이용 약관과 개인정보 처리방침이 적용돼요. 설정 → 평가 환율 → 환율 자동 업데이트에서 다운로드를 끄고 환율을 직접 입력할 수도 있어요.

기기 내 처리

다음 기능은 사용자의 기기에서 실행돼요. 이 기능들이 읽은 내용은 저희에게 전송되지 않아요.

  • 영수증 스캔. 문서 카메라와 텍스트 인식(Apple의 VisionKit 및 Vision)이 기기에서 영수증을 읽어요. 사진은 시스템 사진 선택기에서 가져오며, 이 선택기는 사용자가 고른 사진만 Talea에 제공해요.
  • 받아쓰기. 음성 인식은 기기에서만 실행돼요. 기기가 사용자의 언어를 오프라인으로 인식할 수 없으면, 오디오를 어딘가로 보내는 대신 받아쓰기를 사용할 수 없게 돼요. 오디오는 저장되지 않아요.
  • Apple Intelligence. 지원되는 기기에서 Talea는 Apple의 온디바이스 언어 모델을 사용해, 입력하거나 받아쓰거나 스캔한 내용을 거래 초안으로 바꿔요.
  • 앱 잠금. Face ID, Touch ID, Optic ID 또는 암호는 iOS가 확인해요. Talea가 알 수 있는 것은 잠금 해제 성공 여부뿐이며, 생체 인식 데이터는 절대 보지 않아요.
  • 알림은 기기에 예약되는 로컬 알림이에요. Talea는 푸시 알림을 사용하지 않아요.
  • 가져오기. 사용자가 선택한 CSV 파일과 은행 명세서는 기기에서 읽어요.

권한

Talea는 권한이 필요한 기능을 처음 사용할 때만 해당 권한을 요청해요. 각 권한은 선택 사항이며, iOS 설정 → Talea에서 언제든지 변경할 수 있어요.

권한요청할 때 Talea가 알려 주는 내용
카메라“영수증을 스캔해 검토할 거래를 준비해요.”
마이크“지출을 말로 입력해 거래 초안을 준비해요.”
음성 인식“말로 입력한 지출을 편집할 수 있는 거래 초안으로 바꿔요.”
Face ID“잠금이 켜져 있을 때 Face ID로 Talea의 잠금을 해제해요.”
알림켜 둔 알림을 표시하는 데에만 사용돼요.

추적, 분석, 광고 없음

Talea에는 사용자 계정, 분석, 광고, 추적, 타사 SDK가 없어요. 저희는 데이터를 가지고 있지 않기 때문에 데이터를 판매하거나 대여하거나 공유하지 않아요. Talea의 개인정보 보호 매니페스트에는 Talea가 데이터를 수집하지 않으며 추적도 하지 않는다고 선언되어 있어요.

기기 설정에서 앱 개발자와 분석 정보를 공유하도록 선택한 경우, Apple이 사용자를 식별하지 않는 충돌 보고서와 집계된 App Store 통계를 저희에게 제공할 수 있어요. 이에 대해서는 Apple의 개인정보 처리방침이 적용돼요.

내보내기 및 백업

JSON 백업 내보내기와 CSV 내보내기는 파일 앱이나 iCloud Drive처럼 사용자가 선택한 위치에만 파일을 저장해요. Talea는 내보낸 파일을 암호화하지 않으며, 저장된 파일은 Talea 밖에 있게 되므로 안전한 곳에 보관하세요.

데이터 삭제

  • 설정 → 로컬 데이터 지우기는 이 기기에 있는 기록, 영수증, 초안, 복구본, 그리고 가져오기 대기 중인 모든 항목을 삭제해요. 화면 스타일이나 통화 같은 환경설정은 유지돼요.
  • 앱을 삭제하면 Talea의 모든 데이터가 기기에서 제거돼요.
  • 다른 곳에 만든 사본은 각각 있는 곳에서 삭제해요. 내보낸 파일은 파일 앱에서, iCloud 사본은 iOS 설정 → 사용자 이름 → iCloud → 저장 공간 → Talea에서, 이전 기기 백업은 백업 설정에서 삭제해요.

저희는 사용자의 데이터를 전혀 보관하지 않기 때문에, 저희 쪽에서 접근하거나 정정하거나 삭제할 수 있는 것이 없어요. 데이터 보호 관련 법률에 따른 권리에 대해 궁금한 점이 있으면 저희에게 문의하세요.

아동

Talea는 일반 사용자를 위한 재무 관리 앱이며, 아동을 대상으로 하지 않아요. Talea는 아동을 포함해 누구에게서도 개인정보를 수집하지 않아요.

이 방침의 변경

이 방침을 변경하면 새 버전을 이 주소에 게시하고 상단의 날짜를 업데이트해요. 향후 Talea 버전이 데이터를 수집하기 시작한다면, 해당 버전이 출시되기 전에 이 방침과 App Store의 개인정보 보호 세부사항을 업데이트해요.
